# Data dictionary

_Generated by `python -m sca.docs` from the database catalog. **Simulated** objects are labelled; everything else derives from real Olist data._

Layers: `raw` (as loaded text), then `staging` (typed, cleaned; rejects in `staging.quarantine`) then `core` (star schema) then `marts` (Power BI views). `sim` and `dq` are side schemas.

## Quarantine reason codes

| Code | Meaning |
|---|---|
| MISSING_KEY | Primary key blank |
| DUPLICATE_KEY | Duplicate of an earlier row with the same key |
| MISSING_PURCHASE_DATE | Order without purchase timestamp |
| ORPHAN_CUSTOMER / ORPHAN_ORDER / ORPHAN_PRODUCT / ORPHAN_SELLER | Foreign key has no parent after cleaning |
| DELIVERED_BEFORE_PURCHASE | Delivery timestamp earlier than purchase |
| CANCELED_WITH_DELIVERY_DATE | Canceled/unavailable order carrying a delivery date |
| INVALID_PRICE / INVALID_FREIGHT / INVALID_PAYMENT | price <= 0, freight < 0, payment < 0 |
| INVALID_SCORE | Review score outside 1-5 |
| SUPERSEDED_DUPLICATE | An older review for an order that has a newer one |

Codes observed in the current run: CANCELED_WITH_DELIVERY_DATE, ORPHAN_ORDER, SUPERSEDED_DUPLICATE.
