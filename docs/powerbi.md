# Power BI report

The report lives in `powerbi/` as a **Power BI Project (.pbip)**, plain text (TMDL model + PBIR report), so changes
show up in git diffs. It is generated by `python powerbi/build_pbip.py` from the live `marts` catalog.

> The project has been opened in Power BI Desktop against the real data, and the four pages render as shown in the README screenshots.

## Open it

1. Install Power BI Desktop (free; Microsoft Store). Enable *File > Options > Preview features > 
   Power BI Project (.pbip) save option* and *Store reports using enhanced metadata format (PBIR)* if prompted.
2. Make sure Postgres is up and the pipeline has run (`docker compose up -d`, then `python flows/pipeline.py`).
3. Open `powerbi/SupplyChain.pbip`. Enter the PostgreSQL credentials from `.env` when prompted
   (server `localhost:5432`, database `supply_chain`; change them under *Transform data > Edit parameters*).
4. *View > Themes > Browse for themes > * `powerbi/theme.json`.
5. Home > **Refresh**.

## Pages

| Page | Contents | Data |
|---|---|---|
| Executive Overview | OTD %, fulfillment, review, turnover, stockout rate; monthly trends | real + simulated (labelled) |
| Delivery Performance | OTD by state, review vs lateness, cycle time, carrier handoff | real |
| Supplier Scorecard | Ranked table, lead-time variability scatter | delivery real, `sim_*` simulated |
| Inventory Risk & DQ | At-risk / overstock lists, DQ check status | simulated + DQ |

All DAX measures are defined in the model (`powerbi/SupplyChain.SemanticModel/definition/tables/*.tmdl`) and
mirror the SQL KPI definitions in `sql/40_marts`. Measures computed from simulated data end in **(sim)**.

## Refreshing after a pipeline run (manual on the free tier)

Power BI Service scheduled refresh needs Pro, so it isn't used. The Prefect flow refreshes Postgres at 06:00;
the report is refreshed by opening it and clicking **Refresh**. The *Data-quality checks* table on the last page
shows the latest run and turns up any critical failure.

## Exports

Screenshots of each page are in `docs/img/` and are used in the README. To export a PDF, use *File > Export > PDF* and save it to `powerbi/exports/`.
